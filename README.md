# Customer Segmentation using Machine Learning

## Project Overview

This project applies K-Means Clustering to segment customers based on their Annual Income and Spending Score. Customer segmentation helps businesses understand customer behavior and create targeted marketing strategies.

---

## Features

- Data preprocessing
- Elbow Method for optimal clusters
- K-Means clustering
- Customer visualization
- Export segmented customer data

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- Jupyter Notebook
